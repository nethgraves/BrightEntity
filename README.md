# BrightEntity
A **Magisk/KernelSU/APatch/FolkPatch** module to fix the issue where brightness is too low when maximized on Transsion devices based on Unisoc.

  <img src="https://img.shields.io/badge/github-repo-blue?logo=github&style=for-the-badge" alt="Repo">
  <img src="https://img.shields.io/badge/created by-Nethgraves-green?style=for-the-badge" alt="Created">
</p>

## 🤔 What is this? and how does it work?
Some Unisoc devices has an issue where the maximum brightness level is artificially capped as level 255 on certain port ROMs, and Transsion (maybe others too) has the level higher than 255. This module restores the proper brightness level.

## ✅ Compatible Devices

- Transsion (Itel/Tecno/Infinix)
- Some realme devices (if occur)

## 📦 How to install?
1. Make sure [Hybrid Mount](https://github.com/Hybrid-Mount/meta-hybrid_mount/releases) or [Mountify](https://github.com/backslashxx/mountify/releases) metamodule is installed. After doing so, you're good to go.
2. Download and install the latest **BrightEntity** module.
3. Reboot your device
4. Brightness will be back to normal as is!
